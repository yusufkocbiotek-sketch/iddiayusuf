İsteğini inceledim. Senin belirttiğin parametrelerin **çoğu zaten `dogruOran` fonksiyonunda var** (MS + Alt/Üst 1.5/2.5/3.5 tüm Alt/Üst kombinasyonları ve genel İlk Yarı Alt/Üst 1.5). Eksik olanlar sadece:

- **Ev Sahibi İlk Yarı Alt/Üst 1.5** (Alt/Üst)
- **Deplasman İlk Yarı Alt/Üst 1.5** (Alt/Üst)

Ve dropdown'larda **MS + Alt/Üst için "Alt" seçenekleri eksik** (sadece Üst vardı). Aşağıdaki değişiklikleri yap, başka hiçbir şeye dokunma.

---

## 1️⃣ `dogruOran` fonksiyonuna ekle

`Deplasman İlk Yarı Alt/Üst 0.5_Üst` satırının hemen altına ekle:

```js
  // ✅ EV SAHİBİ İLK YARI ALT/ÜST 1.5
  if(key === "Ev Sahibi İlk Yarı Alt/Üst 1.5_Alt") return iySe < 1.5;
  if(key === "Ev Sahibi İlk Yarı Alt/Üst 1.5_Üst") return iySe > 1.5;

  // ✅ DEPLASMAN İLK YARI ALT/ÜST 1.5
  if(key === "Deplasman İlk Yarı Alt/Üst 1.5_Alt") return iySd < 1.5;
  if(key === "Deplasman İlk Yarı Alt/Üst 1.5_Üst") return iySd > 1.5;
```
